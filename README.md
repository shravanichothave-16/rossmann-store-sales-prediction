# Rossmann Store Sales Prediction

## Project Overview
A Machine Learning project to predict daily sales across Rossmann stores using historical sales data, promotions, holidays, and store information.

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- Google Colab

## Machine Learning Approach
- Data Cleaning and Preprocessing
- Missing Value Handling
- One-Hot Encoding
- Feature Engineering
- Decision Tree Regression
- Bagging Regressor
- Hyperparameter Tuning
- Model Evaluation

## Best Model: Bagging Regressor

**Validation Results:**
- R² Score: 0.88797
- MAE: 815.24
- RMSE: 1247.17

## Dataset
[ Rossmann Store Sales – Kaggle Competition](https://www.kaggle.com/competitions/rossmann-store-sales)

## How to Run
1. Download the datasets from Kaggle.
2. Open the notebook in Google Colab.
3. Upload the required CSV files.
4. Execute the notebook cells in order.
